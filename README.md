# Крамниця — каталог товарів

Навчальний проєкт на React + TypeScript + Vite. Каталог із шести товарів: назва, опис, категорія, ціна, наявність та знижка. Оформлення — Tailwind CSS, умовні класи — `clsx`, об’єднання класів — `tailwind-merge`.

Є пошук за назвою, вибір категорії та перемикач «Лише в наявності». На телефоні картки розташовані в одну колонку, на ширших екранах — у дві або три. Це лише каталог: кошика, оплати, сервера та бази даних немає.

## Запуск через Docker

1. Встановіть Docker Desktop і запустіть його. Для Windows оберіть Linux containers; за потреби увімкніть WSL 2 під час встановлення.
2. Відкрийте термінал у папці проєкту, де лежать `Dockerfile` і `compose.yaml`.
3. Зберіть і запустіть контейнер:

   ```sh
   docker compose up --build -d
   ```

4. Відкрийте [http://localhost:8080](http://localhost:8080).

Локально встановлювати Node.js для цього способу не потрібно. Під час першої збірки потрібен інтернет для завантаження образів і npm-пакетів. Docker збирає застосунок у Node.js, а готову папку `dist` обслуговує nginx.

Зупинити та видалити контейнер:

```sh
docker compose down
```

Переглянути стан або журнали:

```sh
docker compose ps
docker compose logs catalog
```

Після змін у коді повторіть `docker compose up --build -d`. Автоматичного оновлення в Docker-варіанті немає. Якщо порт 8080 зайнятий, змініть у `compose.yaml` значення `8080:80` на `8081:80` і відкрийте порт 8081 у браузері.

Без Compose можна запустити так:

```sh
docker build -t product-catalog .
docker run --rm -d --name product-catalog -p 8080:80 product-catalog
```

Зупинка: `docker stop product-catalog`.

## Запуск без Docker

Потрібен Node.js 24 LTS із npm. У папці проєкту виконайте:

```sh
npm ci
npm run dev
```

Відкрийте адресу, яку виведе Vite, зазвичай [http://localhost:5173](http://localhost:5173). Зміни відображаються автоматично. Зупинка — `Ctrl+C`.

Інші команди:

```sh
npm run build    # перевірка TypeScript і збірка в dist
npm run preview  # локальний перегляд готової збірки
npm run lint     # перевірка ESLint
```

## Структура

```text
src/
  components/
    Card.tsx         # обгортка з children та className
    ProductCard.tsx  # товар, ціна, знижка та наявність
    Section.tsx      # секція із заголовком і children
  data/products.ts   # масив товарів
  types/Product.ts   # тип Product
  App.tsx            # фільтри, .map() і стани каталогу
  index.css          # підключення Tailwind і базові стилі
Dockerfile           # збірка та nginx
compose.yaml         # запуск на порту 8080
```

## Як працюють вимоги завдання

- `Product` містить `id`, `name`, `description`, `price`, `category`, `inStock` та необов’язковий `discount`.
- `App.tsx` відображає товари через `.map()` із ключем `product.id`.
- `ProductCard` показує «Є в наявності» або «Немає в наявності». Якщо знижка більша за нуль, показує відсоток, стару ціну та нову ціну в гривнях, округлену до цілої гривні. Без знижки ці блоки приховані.
- Необов’язковий `badgeText` має значення `Новинка` за замовчуванням через деструктуризацію. Для першого товару передано `Популярне`.
- `Card` об’єднує базові класи й `className` через `twMerge(clsx(...))`. У `ProductCard` бібліотека `clsx` задає кольори за категорією та наявністю.
- `Section` приймає `title` і `children` та обгортає каталог.
- Для порожнього масиву є повідомлення «Товарів поки немає». Якщо в непорожньому каталозі немає жодного товару з `inStock: true`, з’являється «Усі товари розпродані». Перевіряється весь масив, незалежно від фільтрів.

## Як перевірити різні стани

Дані змінюються у `src/data/products.ts`:

1. Залиште порожній масив `products: Product[] = []`, щоб побачити порожній каталог.
2. У всіх товарів задайте `inStock: false`, щоб побачити повідомлення про розпродаж.
3. Видаліть `discount` у товару — його стара ціна та відсоток знижки зникнуть.
4. Введіть у пошуку неіснуючу назву — з’явиться повідомлення, що товари не знайдені.

Після перевірки поверніть початкові дані. У Docker після редагування потрібна повторна збірка.

Довідка: [Tailwind із Vite](https://tailwindcss.com/docs/installation/using-vite), [багатоетапна збірка Docker](https://docs.docker.com/build/building/multi-stage/).
